# Natural gas and crude oil market monitoring application in Python

## Current features:
1. Natural gas fundamentals (supply, consumption, import/export) for US regions from EIA API
2. Weather alerts in US pulled from US NOAA API directly, updated live with a button
3. Map visual displaying global information about: oil/gas terminals, import/export hubs, oil plants, and many more. Dataset is gathered from Global Energy Monitor (GEM).
